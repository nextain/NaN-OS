# Naia Memory 0.2.2 제품 동결 및 경쟁력 보고서

- 동결일: 2026-08-24
- 대상 제품: Naia Shell 0.2.2
- 판정: **제품 포함 가능(안정화선 동결), 글로벌 우위 공개 주장은 보류**

## 동결선

Naia Shell 0.2.2 설치 빌드는 다음 소스를 커밋 단위로 고정한다.

| 구성요소 | 동결 커밋 | 역할 |
|---|---|---|
| naia-shell | `7aa90a8e` 기반 + 본 동결 변경 | 제품 UI, 설정, 설치 산출물과 런타임 스테이징 |
| naia-agent | `bd70c44c39d32f693eab99994374194c21e37f7f` | 메모리 설정 해석, 저장·회상 UC, 격리와 프롬프트 연결 |
| naia-memory | `46c300825a22478e062772ec7cab234be956328f` | 영속 저장, 사실/에피소드, 검색, 압축, 오프라인 임베딩, Naia 게이트웨이 인증 |

Shell의 설치 워크플로가 Agent와 Memory를 각각 위 커밋으로 checkout한 뒤 `pnpm install --frozen-lockfile`을 실행한다. 따라서 Agent의 로컬 파일 의존성(`file:../naia-memory`)도 설치 빌드에서는 재현 가능한 단일 조합으로 닫힌다.

이 동결은 **제품 안정화선**이다. `naia-memory`의 `feat/memory-bench-harness-and-fixes` 연구 브랜치와 미승격 벤치 실험은 0.2.2에 포함하지 않는다.

## 릴리스 검증

동결 검증 중 기존 Memory 핀(`b88f3f0`)이 Agent가 전달한 Naia 게이트웨이 인증 방식을 소비하지 않아, LLM 사실 추출·요약 요청이 잘못된 인증 헤더로 나가는 결함을 발견했다. 연구선 전체를 합치지 않고 해당 인증 수정만 안정화선에 이식한 `46c3008`로 핀을 교체했다.

| 경계 | 결과 | 근거 |
|---|---|---|
| naia-memory | 통과 | 23 files, 385 tests; typecheck; build |
| naia-agent 메모리 UC/계약 | 통과 | 5 files, 98 tests; build. 저장 경로·프로젝트 격리·재시작 영속성·stdio UC·임베딩/LLM 인증 |
| naia-shell 런타임 핀/플랫폼 | 통과 | 2 files, 53 tests; production build |

검증은 CPU에서 수행했으며 GPU 1은 사용하지 않았다.

### 적대 검토 상태

동결 과정의 자체 적대 검토에서 두 가지 릴리스 결함을 실제로 찾아 수정했다. 첫째, 기존 Memory 핀의 게이트웨이 인증 헤더 불일치다. 둘째, 릴리스 노트에 연결했던 이슈 번호가 Memory 배선 이슈가 아니었던 매핑 오류다. 현재 문서와 핀에는 두 수정이 반영돼 있다.

OpenCode와 Claude 헤드리스 교차 검토도 요청했으나 제한 시간 안에 범위가 닫힌 판정을 반환하지 못했다. 따라서 외부 다중 모델 적대 리뷰는 **미완료(NOT_RUN)** 로 기록하며, 이 보고서를 정식 `RELEASE_ELIGIBLE` 교차 검토 판정으로 해석해서는 안 된다. 제품 동결 판정은 위 결정론 테스트와 코드 경계 검증에 근거한다.

## 0.2.2에서 실제 제공되는 기능

- 대화의 사용자·어시스턴트 턴을 저장하고 다음 대화에서 관련 원문을 회상한다.
- 프로세스 재시작 뒤에도 로컬 JSON 저장소에서 기억을 복원한다.
- `NAIA_HOME/memory/naia-memory.json`에 저장해 운영·개발 프로필을 분리한다.
- 워크스페이스에서 유도한 필수 `project` 키와 기본 `strict` 모드로 교차 프로젝트 회상을 차단한다.
- 설정에서 Local/Qdrant, 키워드/오프라인/호환 API 임베딩, 휴리스틱/LLM 사실 추출을 선택한다. 잘못된 설정은 조용히 축소하지 않고 메모리 기능을 격리한다.
- 한국어를 포함한 다국어 오프라인 모델 `multilingual-e5-large`와 `paraphrase-multilingual-MiniLM-L12-v2`를 선택할 수 있다. 기본값을 특정 언어 전용으로 강제하지는 않는다.
- 컨텍스트 압축은 결정론 폴백과 주입 가능한 LLM 요약기를 제공한다.

## 성능과 위치

### 공개 가능한 강점

동일 프로젝트의 연구선에서 측정한 MIRACL 한국어 전체 코퍼스(1,486,752 passages, 213 queries, exact cosine CPU) 결과는 nDCG@10 **0.6526**, Recall@100 **0.9233**, Success@1 **0.5962**, Success@10 **0.9202**, MRR **0.7228**이다. 프로토콜이 맞는 역사적 MIRACL BM25+mDPR 기준 0.609/0.900보다 각각 +0.0436 nDCG@10, +0.0233 Recall@100이다.

이는 Naia Memory의 한국어 검색 기반이 약하지 않으며, 대규모 전체 코퍼스에서도 경쟁력 있는 검색 품질을 낼 수 있다는 근거다. 또한 100k 합성 SQLite CPU 측정에서는 surface recall p50/p95 **4.00/5.34ms**, deep recall **40.68/43.78ms**, 주입 **1,631 facts/s**를 기록했다.

### 해석 제한

- MIRACL 수치는 **연구선 검색기**의 측정이며 0.2.2 제품 조합의 end-to-end 대화 기억 점수가 아니다.
- 사용 모델은 MIRACL 학습 데이터를 사용했으므로 zero-shot 결과가 아니다.
- Mem0, Hindsight, Graphiti, Letta 등과 동일 입력·동일 judge·반복 실행으로 완결된 적격 영수증이 아직 없다. 따라서 “글로벌 엔진보다 우수하다”는 주장은 할 수 없다.
- SQLite 100k 지연은 합성 벤치이며 현재 기본 제품 경로인 LocalAdapter의 사용자 체감 지연을 직접 대변하지 않는다.
- 결정론 압축은 기존 rolling-summary 팽창을 161.8%에서 29.7%로 줄였지만 사실 충실도는 약 30~50% 한계가 있다. 실험용 LLM 요약기는 16.5% 크기에서 anchor 충실도 90%를 보였으나 제품 기본 품질 보장은 아니다.

따라서 현재 위치는 다음처럼 표현하는 것이 정확하다.

> **한국어 대규모 검색은 강한 편이며, 제품에는 안전한 로컬 영속 기억과 워크스페이스 격리가 실제 배선돼 있다. 다만 장기 대화의 업데이트·모순 해결·망각·압축까지 포함한 글로벌 memory-engine 종합 우위는 아직 증명 전이다.**

성숙도 관점에서는 “벤치마크 전용 프로토타입”이 아니라 **사용 가능한 초기 제품 메모리**다. 반면 “글로벌 선도 범용 기억 엔진”으로 공개하기에는 경쟁 엔진 동조건 평가와 제품 E2E 장기 기억 평가가 부족하다.

## 차별점

Naia Memory의 현재 차별점은 단순 벡터 검색 점수 하나가 아니다.

1. Shell 설정, Agent UC, Memory 엔진의 경계를 나눠 제품에 연결했다.
2. 기억 파일을 Naia 프로필 경계 안에 두고 프로젝트별 누설을 fail-closed로 막는다.
3. 한국어를 우선 검증하면서도 특정 언어 전용 분기 대신 다국어 임베딩 공급자 경계로 확장한다.
4. 사실, 에피소드, working/semantic memory, 압축과 향후 consolidation을 하나의 인지 메모리 구조로 발전시킬 수 있다.
5. 연구 결과를 즉시 제품 기본값으로 넣지 않고, 재현성과 자원 비용·마이그레이션 조건을 통과한 변경만 순차 승격한다.

## 0.2.2 이후 필요한 보강

1. 0.2.2 고정 조합에서 실제 Shell 대화의 저장 → 종료 → 재시작 → 회상 FE/UC E2E를 릴리스마다 실행한다.
2. LocalAdapter 저장 벡터에 embedding-space identity와 명시적 재색인 절차를 제품선에 승격한다.
3. 한국어·영어·일본어 독립 저자 코퍼스에서 Naia, Mem0, Hindsight, Graphiti, Letta를 동일 계약으로 반복 측정한다.
4. 업데이트·모순·삭제·시간 감쇠·프로젝트 누설·요약 충실도를 검색 점수와 분리한 장기 기억 제품 벤치를 만든다.
5. 자원 균형이 좋은 multilingual-e5-small 후보를 Shell/Agent closed union, 차원 호환, 저장소 마이그레이션까지 통과시킨 뒤 제품 선택지로 승격한다.

## 출시 문구

0.2.2에는 다음 수준으로 소개할 수 있다.

> Naia 0.2.2는 대화를 로컬에 지속 저장하고 워크스페이스별로 격리해 다시 회상하는 Naia Memory를 포함합니다. 한국어를 지원하는 오프라인 시맨틱 검색을 선택할 수 있으며, 연구 기능은 안정성 검증 뒤 제품선에 순차 반영합니다.

“세계 최고”, “Mem0/Graphiti보다 우수”, “완전한 인간형 기억” 표현은 현재 증거 범위를 넘으므로 사용하지 않는다.
