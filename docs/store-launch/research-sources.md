# 공식 규격 조사 기록

조사 기준일: 2026-08-05. 아래 링크는 제출 직전에 다시 확인한다.

## Steam

- [Steam Direct](https://partner.steamgames.com/steamdirect/): 앱당 미화 100달러, 첫 출시 전 수수료 결제 후 30일 대기, Coming Soon 페이지 최소 2주. 비게임 소프트웨어는 Animation & Modeling, Audio/Video Production, Design & Illustration, Photo Editing, Educational & Tutorials, Finance & Accounting, Player Tools, SteamVR Tools 범주가 명시되어 있다.
- [Store Graphical Assets](https://partner.steamgames.com/doc/store/assets/standard): Header 920×430, Small 462×174, Main 1232×706, Vertical 748×896, 실제 제품 화면 최소 5장(1920×1080 이상, 16:9).
- [Library Assets](https://partner.steamgames.com/doc/store/assets/libraryassets): Library Capsule 600×900, Header 920×430, Hero 3840×1240(텍스트 금지), Logo 최대 1280 너비 또는 720 높이의 투명 PNG.
- [Review Process](https://partner.steamgames.com/doc/store/review_process): 스토어와 빌드 심사는 통상 3~5영업일이며 최소 7영업일 여유 권장. 출시 시 제공되지 않는 기능을 문구·이미지에 넣으면 안 된다.
- [Content Survey](https://partner.steamgames.com/doc/gettingstarted/contentsurvey): 실행 중 생성되는 AI 콘텐츠는 Live-Generated로 신고하고 불법 콘텐츠 방지 장치를 설명해야 한다.
- [Store Page](https://partner.steamgames.com/doc/store/page): 설명 영역에 외부 링크를 직접 넣지 않고 지정된 링크 필드를 사용한다.

## Microsoft Store

- [Win32 앱 배포](https://learn.microsoft.com/en-us/windows/apps/distribute-through-store/how-to-distribute-your-win32-app-through-microsoft-store): MSIX 또는 서명된 오프라인 MSI/EXE 경로. 비패키지 앱은 게시자가 호스팅·서명·업데이트를 책임진다.
- [MSI/EXE 이미지](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msi/screenshots-and-images): 실제 화면 1장 필수, 4장 이상 권장, 최대 10장. 1:1 box art 필수, 2:3 poster art 권장.
- [스토어 입력 필드](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/pwa/add-and-edit-store-listing-info): 설명 10,000자, 기능별 200자·최대 20개, Short description은 270자 이하 권장, 키워드 최대 7개.
- [이미지·트레일러 규격](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/pwa/screenshots-and-images): 데스크톱 스크린샷 1366×768 이상 PNG, 최대 50MB. 앱 타일 300×300. Super hero art 1920×1080 또는 3840×2160, 텍스트와 UI 금지. 트레일러는 1920×1080 MP4/MOV, 썸네일 1920×1080 PNG.
- [Microsoft Store Policies](https://learn.microsoft.com/en-us/windows/apps/publish/store-policies): live generative AI는 메타데이터와 Partner Center에 고지하고, 부적절한 출력 신고 수단을 제공해야 한다.

## 적용 판단

- Microsoft의 PWA 이미지 문서는 세부 공통 규격을 제공하지만, Naia 제출 경로의 필수 여부는 MSI/EXE 전용 페이지를 우선한다.
- Naia는 게임이 아니라 데스크톱 앱이다. Microsoft 자료의 게임/Xbox 전용 자산은 참고용 선택 자산으로만 만든다.
- Steam의 “gameplay screenshot”은 Naia의 경우 실제 앱 사용 화면으로 해석하되, 콘셉트 아트나 마케팅 문구를 스크린샷 슬롯에 넣지 않는다.
