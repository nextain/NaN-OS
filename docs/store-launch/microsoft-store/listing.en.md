# Microsoft Store Copy — English

## Product name

Naia

## Short description

A visual AI companion that brings your preferred AI models, workspace, and tools together in one character-centered desktop experience.

## Description

Naia is a desktop visual agent you can see and talk to. Ask questions in text, follow streamed responses from your connected AI model, and manage model and workspace settings in one place.

Choose how you connect. Select a supported online model or local configuration and switch without restarting the app. Some providers may require a separate account, API key, credits, or usage fees. Available capabilities vary by provider and hardware.

Keep conversation and practical work in the same experience. Naia's shell is designed to let an agent use authorized workspaces and tools. Text is the baseline response mode, with avatar and voice expression paths available depending on configuration. Advanced local voice and avatar features may require additional models and a compatible GPU.

Generative AI notice: Naia displays live generative AI content in response to user input. AI output may be inaccurate or unexpected; verify important information against original sources. Users can report inappropriate output through the in-app reporting or support channel.

## Product features

1. Streaming text conversations
2. Multiple AI provider and model settings
3. Workspace and tool connections
4. Character-centered desktop interface
5. Optional voice and avatar expression paths
6. Korean and English interface
