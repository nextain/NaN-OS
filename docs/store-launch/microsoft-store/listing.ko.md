# Microsoft Store 문안 — 한국어

## 제품 이름

Naia

## 짧은 설명

내가 고른 AI 모델, 작업 공간, 도구를 하나의 캐릭터 중심 데스크톱 화면에서 연결하는 비주얼 AI 동반자입니다.

## 설명

Naia는 사용자가 직접 보고 대화하는 데스크톱 비주얼 에이전트입니다. 텍스트로 질문하고 연결한 AI 모델의 답변을 실시간으로 확인하며, 모델 설정과 작업 공간을 한곳에서 관리할 수 있습니다.

원하는 연결 방식을 선택하세요. 지원되는 온라인 모델 또는 로컬 구성을 고르고 앱을 다시 시작하지 않고 전환할 수 있습니다. 일부 제공자는 별도 계정, API 키, 크레딧 또는 이용 요금이 필요할 수 있으며 제공자와 하드웨어에 따라 사용할 수 있는 기능이 달라집니다.

대화와 실제 작업을 한 화면에서 이어가세요. Naia의 셸은 에이전트가 허용된 작업 공간과 도구를 사용할 수 있도록 설계되어 있습니다. 텍스트가 기본 응답 방식이며, 구성에 따라 아바타와 음성 표현 경로를 사용할 수 있습니다. 고급 로컬 음성·아바타 기능은 추가 모델과 호환 GPU가 필요할 수 있습니다.

생성형 AI 안내: Naia는 사용자 입력에 따라 실시간 생성형 AI 콘텐츠를 표시합니다. AI 응답은 부정확하거나 예상하지 못한 내용을 포함할 수 있으므로 중요한 판단에는 원문과 별도 근거를 확인하세요. 부적절한 출력은 앱의 신고/지원 경로를 통해 개발자에게 알릴 수 있습니다.

## 제품 기능

1. 스트리밍 텍스트 대화
2. 여러 AI 제공자와 모델 설정
3. 작업 공간과 도구 연결
4. 캐릭터 중심 데스크톱 인터페이스
5. 구성에 따른 음성·아바타 표현
6. 한국어와 영어 인터페이스
