## Short Description

Naia is a visual AI companion that brings your AI models, workspace, and tools together in one character-centered desktop experience.

## About This Software

### Meet your AI in one desktop window

Naia is a desktop visual agent you can see and talk to. Ask questions in text, follow streamed responses from your connected AI model, and manage connections and workspace settings in one place.

### Connect the model you prefer

Choose from supported online models or a local configuration and switch without restarting the app. Some providers may require a separate account, API key, credits, or usage fees. Available capabilities vary by provider.

### Bring conversation and work together

Naia is more than a chat window. Its shell is designed to connect an agent with workspaces and tools, keeping conversation and practical desktop workflows in the same experience.

### Responses with a visual presence

Text is the baseline response mode. Depending on your configuration and hardware, Naia can also use avatar and voice expression paths. Advanced local voice and avatar features may require additional models and a compatible GPU.

### Generative AI notice

This software displays live generative AI content in response to user input. AI output may be inaccurate or unexpected; verify important information against original sources. Users can report inappropriate output through the in-app reporting or support channel.

## Key Features

- Streaming text conversations
- Multiple AI provider and model settings
- Workspace and tool connections
- Character-centered desktop interface
- Optional voice and avatar expression paths
- Korean and English interface
