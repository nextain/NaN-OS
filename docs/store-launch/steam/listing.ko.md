# Steam 스토어 문안 — 한국어

> 분류 후보: Software / Player Tools. 단, 현재 제품 적합성을 Valve에 먼저 확인한다.

## 짧은 설명

Naia는 AI 모델, 작업 공간, 도구를 하나의 캐릭터 중심 데스크톱 화면에서 연결하는 비주얼 AI 동반자입니다.

## 상세 설명

### AI를 창 하나에서 만나세요

Naia는 사용자가 직접 보고 대화하는 데스크톱 비주얼 에이전트입니다. 텍스트로 질문하고, 연결한 AI 모델의 답변을 실시간으로 확인하며, 필요한 설정과 작업 공간을 한곳에서 관리할 수 있습니다.

### 원하는 모델을 연결하세요

지원되는 온라인 모델 또는 로컬 구성을 선택하고 앱을 다시 시작하지 않고 전환할 수 있습니다. 일부 제공자는 별도 계정, API 키, 크레딧 또는 이용 요금이 필요할 수 있으며 사용 가능한 기능은 제공자에 따라 달라집니다.

### 작업 공간과 도구를 함께 사용하세요

Naia의 셸은 대화 화면에 그치지 않습니다. 연결된 에이전트가 작업 공간과 도구를 다룰 수 있도록 구성되어 있어 대화와 실제 작업 흐름을 한 화면에서 이어갈 수 있습니다.

### 캐릭터로 표현되는 응답

Naia는 텍스트를 기본으로 응답하며, 구성과 하드웨어에 따라 아바타·음성 표현 경로를 사용할 수 있습니다. 일부 고급 로컬 음성·아바타 기능은 추가 모델과 호환 GPU 구성이 필요합니다.

### 생성형 AI 안내

이 소프트웨어는 사용자의 입력에 따라 실시간 생성형 AI 콘텐츠를 표시합니다. AI 응답은 부정확하거나 예상하지 못한 내용을 포함할 수 있으므로 중요한 판단에는 원문과 별도 근거를 확인하세요. 부적절한 출력은 앱의 신고/지원 경로를 통해 개발자에게 알릴 수 있습니다.

## 핵심 기능

- 스트리밍 텍스트 대화
- 여러 AI 제공자와 모델 설정
- 작업 공간과 도구 연결
- 캐릭터 중심 데스크톱 인터페이스
- 구성에 따른 음성·아바타 표현
- 한국어와 영어 인터페이스

## 시스템 요구 사항 초안

### 최소

- 운영체제: Windows 10/11 64-bit
- 프로세서: 64-bit 듀얼 코어 이상
- 메모리: 8 GB RAM
- 그래픽: WebView2를 지원하는 GPU
- 네트워크: 온라인 AI 제공자를 사용할 때 광대역 연결 필요
- 저장 공간: 최종 번들 측정 후 입력

### 권장

- 운영체제: Windows 11 64-bit
- 메모리: 16 GB RAM
- 그래픽: 하드웨어 가속 지원 GPU
- 추가 사항: 로컬 음성·아바타 모델은 별도 GPU·저장 공간 요구 사항이 적용될 수 있음
