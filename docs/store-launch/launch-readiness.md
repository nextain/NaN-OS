## 권장 출시 순서

1. Microsoft Partner Center 앱 이름 `Naia` 예약.
2. 개인정보처리방침·지원·AI 신고 페이지 공개.
3. MSIX 또는 서명된 오프라인 MSI/EXE 배포 방식 확정.
4. 깨끗한 Windows 11 PC에서 설치, 최초 실행, 로그인/설정, 대화, 삭제를 검증.
5. 실제 출시 빌드로 화면 2장과 30~45초 트레일러를 추가 촬영.
6. Microsoft Store 제출 및 인증 피드백 반영.
7. Valve에 비게임 소프트웨어 적합성 확인 후에만 Steam Direct 비용 지불.
8. Steam 승인이 가능하면 Coming Soon을 최소 2주 운영하고 빌드·스토어 심사를 최소 7영업일 앞서 요청.

## 권장 포지셔닝

**한 줄:** 나만의 모델과 작업 공간을 연결하는 비주얼 AI 동반자.

핵심 차별점은 캐릭터 외형 자체가 아니라 다음 조합이다.

- 여러 AI 모델 연결과 재시작 없는 전환
- 텍스트 중심의 실제 데스크톱 대화
- 작업 공간과 도구를 연결하는 에이전트 셸
- 선택 가능한 아바타·음성 표현 경로
- 로컬 우선 구성을 포함한 사용자가 고르는 연결 방식

“항상 켜져 있다”, “완전한 로컬”, “모든 음성 기능 지원”처럼 현재 근거보다 넓은 표현은 사용하지 않는다.
