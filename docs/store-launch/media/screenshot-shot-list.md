# 실제 화면 촬영 목록

## 이미 확보된 화면

1. NVA 프로필이 적용된 메인 화면
2. 설정 화면
3. 로그인/계정 연결 화면

## 추가로 반드시 촬영할 화면

4. **대화와 스트리밍 응답**: 출시 빌드에서 일반적인 질문 1개와 완성된 답변이 보이는 상태. 개인 정보, API 키, 내부 URL 금지.
5. **작업 공간·도구 화면**: 허용된 샘플 작업 공간과 도구 앱이 보이는 상태. 고객 데이터·비공개 저장소명 금지.

## 선택 화면

6. 캐릭터/음성 설정: 실제 출시에서 지원하는 옵션만 노출.
7. BGM 또는 환경 사이드카: 재생 상태가 실제로 검증된 화면.

## 촬영 규격

- 1920×1080 PNG, 16:9
- Windows 디스플레이 배율 100%
- 마우스 포인터 숨김
- 알림·개인 계정명·API 키·파일 경로 제거
- 마케팅 문구나 프레임을 합성하지 않음
- 한국어와 영어 목록을 낼 경우 언어별 실제 UI 캡처 권장
